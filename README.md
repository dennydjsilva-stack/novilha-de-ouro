# Pousada Novilha de Ouro

Site da Eco Pousada, Clube e Camping em Caldas Novas, GO. Arquivo único (`index.html`), sem etapa de build.

- Site público: abra `index.html` (ou a página do GitHub Pages).
- Painel da equipe: adicione `#admin` ao endereço, ou use "Área da equipe" no rodapé.
- Para guardar os dados entre aparelhos, cole o URL do Apps Script em `planilhaUrl` no começo do script.
